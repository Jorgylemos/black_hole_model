## 🌌 A love for astronomy, physics, and programming.

<p style="font-size: 16px;">
The goal of this project is to develop a model capable of identifying objects in space.
The idea is for the model to be able to distinguish between black holes, neutron stars, and quasars, without any overlap in the data.
<b>For now, I am simply adding code as I go through the studies and articles I’ve read.</b>
</p>

## How do I execute it?

### 1. Enable venv environment
```
$ source ./venv/bin/activate
```

### 2. Install dependencies from requirements
```
$ pip install -r requirements.txt
```

### 3. Execute script (empty is no arguments)
```
$ task start EMPTY | <DATASET_PATH>
```
